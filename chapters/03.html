CHAPTER 03 / 28 · FOUNDATIONS

平稳性

同样的局部起伏，为什么一个过程能有稳定的均值与协方差，另一个会不断漂移？从单位根、差分和 ADF/KPSS 读懂这一差别。

01 · 严平稳与弱平稳不是一回事

平稳性关心统计性质在时间平移后是否保持一致。严平稳要求有限维联合分布在整体平移时间后不变；弱平稳要求有限且稳定的均值、方差与只依赖滞后量的协方差。

E[Yt]=μCov(Yt,Yt−k)=γk

有有限二阶矩的严平稳过程也是弱平稳，但仅满足弱平稳通常不推出严平稳。重要的是，弱平稳不意味着观测互相独立：一个 AR(1) 过程可以既平稳又有显著自相关。

02 · 单位根是“冲击累积”的一种机制

随机游走 Y_t = Y_(t−1) + ε_t 让每个新冲击永久成为未来水平的一部分。若创新相互独立、零均值且方差为 σ²，初始值与创新独立，则 Var(Y_t)=Var(Y_0)+tσ²，方差随时间增加。

Yt=Yt−1+εtVar(Yt)=Var(Y0)+tσ2

对比 Y_t = 0.6Y_(t−1)+ε_t：旧冲击的影响按 0.6 的幂次衰减，满足通常的创新条件并选取合适初始分布时，可以存在平稳解。系数接近 1 会让冲击消退得很慢，单从短期曲线不易看清。

03 · ADF 与 KPSS 的原假设方向相反

ADF 的原假设通常为序列存在单位根；KPSS 在设定 regression="c" 时，以围绕常数水平平稳为原假设；regression="ct" 则是围绕确定性趋势平稳。检验方向不同，不要把两者的 p 值当成相同含义。

检验H₀p 值小的典型解释
ADF有单位根有证据反对单位根
KPSS(c)水平平稳有证据反对水平平稳
KPSS(ct)趋势平稳有证据反对趋势平稳

若两个检验同时显著，或同时不显著，应检查断点、样本长度、趋势与截距设定、创新过程以及检验功效。未拒绝原假设不是证明原假设为真。

04 · 差分究竟消除了什么

一阶差分将序列转成相邻两期的变化量。对标准随机游走，差分后就是创新冲击；但对已经平稳的序列，额外差分可能带来不必要的负自相关和预测不确定性。

Δyt=yt−yt−1Δsyt=yt−yt−s

确定性趋势可以通过回归趋势项等方法处理；长期结构断点也可能需要分段或干预建模。不要因为一张图向上就不加区分地做多阶差分。

05 · 实验：平稳 AR(1) 与随机游走

代码使用固定随机种子产生 240 个创新值。需要 numpy 和 statsmodels。单次样本中 p 值具有随机性，因此我们报告计算流程而不伪造必然显著的输出。

import numpy as np
from statsmodels.tsa.stattools import adfuller, kpss

rng = np.random.default_rng(2026)
innovation = rng.normal(size=240)
walk = np.cumsum(innovation)
ar = np.zeros(240)
for i in range(1, len(ar)):
    ar[i] = 0.6*ar[i-1] + innovation[i]
for name, seq in (("AR1", ar), ("walk", walk)):
    p_adf = adfuller(seq, regression="c", autolag="AIC")[1]
    p_kpss = kpss(seq, regression="c", nlags="auto")[1]
    print(name, "ADF:", round(p_adf, 4), "KPSS:", round(p_kpss, 4))
assert len(np.diff(walk)) == 239

KPSS 使用有限表格近似的 p 值区间，极端统计量可能产生范围警告。论文或报告中应写明样本时段、显著性水平、是否使用趋势项、滞后选择方式及异常点策略。

06 · 什么时候不必强行平稳化

某些模型（如 ARMA）对平稳性有明确理论要求；ARIMA 通过差分表达积分过程，指数平滑、确定性趋势回归与状态空间模型则可在恰当设定下处理变化的水平。机器学习模型也未必要求原序列全局平稳，但需要注意时间漂移导致的外推风险。

常见误解：“如果序列不平稳，所有预测与统计推断一定失败”是错误的绝对化表述。应先说明具体模型、估计目标与假设，再决定是否变换数据。

用滚动回测验证差分是否改善预测，并且检查是否存在过度差分、方差不稳定和结构性变点。
