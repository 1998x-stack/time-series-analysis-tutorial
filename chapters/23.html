CHAPTER 23 / 28 · RECURRENT NETWORKS

循环神经网络

从“手工设计特征”转入“让网络自己学”：RNN 用隐藏状态携带记忆，却受梯度消失所困；LSTM 用门控与细胞状态为梯度开出一条加法通道。三章深度学习从这一章开始。

机制图解 · 原生数学排版 · 可复现模拟 · 训练边界

前面九章我们都在“人工指定结构”：ARIMA 的阶数、树模型的切分、Prophet 的分量。循环神经网络换了一种思路——它自己维护一个状态向量来记忆历史，并在所有时间步共享同一组权重。这种“循环”的结构正是为序列而生的。

但它也带来一个经典难题：梯度沿时间反向传播时会指数衰减或爆炸。理解这个问题，才理解 LSTM 与 GRU 为什么长成现在这样。

01 · RNN 的核心思想

在每一步 t，RNN 同时接收当前输入 xt 与上一时刻的隐藏状态 ht−1，算出新的隐藏状态与输出：

ht=tanh(Wihxt+bih+Whhht−1+bhh)
注意 Wih、Whh 在所有时间步共享：不管你处理多长的序列，参数数量都不变，变的只是循环次数。

02 · 梯度消失与爆炸

训练靠的是时间反向传播（BPTT）：误差信号要沿时间一步步往回乘。每一步都会乘上隐状态递推的雅可比矩阵，于是多步的乘积决定了远端梯度的量级。

∂ht∂hk=∏j=k+1t∂hj∂hj−1
若各步雅可比矩阵的谱范数大致 < 1，连乘就指数衰减（梯度消失）；> 1 则指数增长（梯度爆炸）。

这个现象在早期分析中就被指出（Hochreiter 1991 年的学位论文，以及 Bengio 等人 1994 年的分析）。梯度爆炸可以用梯度裁剪缓解，但梯度消失是结构性的：信息要穿过很多非线性变换才能回到远处。

问题现象原因后果
梯度消失梯度趋近于零雅可比谱范数 < 1，连乘衰减学不到长期依赖
梯度爆炸梯度指数增大雅可比谱范数 > 1，连乘放大更新不稳定、训练发散
w=0.90：12 步后梯度约为初始的 0.28；w>1 时随步数指数放大。

教学示意：用标量递推 gₕ=wʰ 近似梯度沿时间回传的缩放，横轴为 1 到 12 个回传步，柱高按最大值归一。真实的衰减速率还取决于激活函数导数与每步输入，并非固定曲线。

03 · LSTM：门控与细胞状态

长短期记忆网络（LSTM）由 Hochreiter 与 Schmidhuber 于 1997 年提出，关键创新是引入细胞状态 ct 与三个门。细胞状态的更新以加法为主，因此梯度可以沿它更稳定地流动。

ct=ft⊙ct−1+it⊙c~
ft 是遗忘门，it 是输入门，c̃ 是候选状态；⊙ 为逐元素乘。隐藏状态由输出门 ot 与 tanh(ct) 得到：ht = ot ⊙ tanh(ct)。三个门都是 sigmoid 输出 0–1 的开关。

根据官方实现（如 PyTorch nn.LSTM）的参数结构，门控与候选状态的完整形式为：

  • 遗忘门：f_t = σ(W_f [h_{t-1}, x_t] + b_f)，决定丢弃多少旧信息；
  • 输入门：i_t = σ(W_i [h_{t-1}, x_t] + b_i)，与候选 c̃_t = tanh(W_c [h_{t-1}, x_t] + b_c) 共同决定写入什么；
  • 输出门：o_t = σ(W_o [h_{t-1}, x_t] + b_o)，决定把多少细胞状态暴露为隐藏状态。
历史细节：原始 1997 年的 LSTM 并没有遗忘门，遗忘门是在 Gers、Schmidhuber 与 Cummins（2000）之后才普遍加入的。如今“LSTM”默认指带遗忘门的版本，但引用时应区分这个差异。

04 · GRU：更简洁的门控

门控循环单元（GRU）由 Cho 等人于 2014 年提出，把 LSTM 的三个门简化为两个——更新门与重置门，并且不再有独立的细胞状态，直接用隐藏状态携带信息。

  • 更新门：控制保留多少旧隐藏状态、写入多少新候选；
  • 重置门：控制计算候选状态时忽略多少旧信息。

GRU 参数更少、训练更快。它和 LSTM 的表现差异高度依赖数据与任务，没有普遍最优；在数据量与序列长度都不是极端值的情况下，二者常接近。所以选型应在自己的验证集上比，而不是凭“新版更好”的直觉。

05 · 双向与堆叠结构

双向 RNN/LSTM：正向与反向各读一遍序列，每个时间步拼接两个方向的隐藏状态，从而同时利用过去与“未来”的上下文。它对分类、异常检测、缺失填补很有用。但在预测任务中，双向结构会用到未来的观测，属于信息泄露，因此纯预测不能用双向。

堆叠 LSTM：把多层 LSTM 垂直堆叠，下层输出作为上层输入，以逐层提炼更长的时间结构。层数过多会过拟合且计算昂贵，常见做法是 1–3 层，并用验证集确定。

一致的性质：无论 RNN 还是 LSTM，它们都是自回归式的——训练时权重在时间上共享，因此要求输入尺度稳定（先标准化），并且要用上一章的时序验证来评估。

06 · Seq2Seq 与自回归生成

序列到序列（Seq2Seq）架构由编码器与解码器两部分组成：编码器读完历史窗口，把它压缩成一个上下文向量；解码器从该向量出发，逐步生成未来的多个值。它在机器翻译中成名，后被引入多步预测。

引入深度学习后，处理序列的范式至少可以分三类：

  • 滑窗回归：用固定长度历史直接预测下一个（或下 h 个）值，对应前面几章的树模型；
  • 逐点标注：每个时间步都有输出，适合异常检测、分类、缺失填补；
  • 自回归生成：逐步生成未来序列，每步的预测值又作为下一步的输入，适合多步预测。

自回归生成有个内在弱点叫 exposure bias：训练时喂的是真实值，推理时喂的是自己的预测，两者分布不一致，误差会逐步累积。第 25 章的 Transformer 同样面对这个问题。

07 · 训练技巧

  • Teacher Forcing：解码时用真实值作为下一步输入，加速收敛；但应混入一定比例“用自己预测作输入”的样本，以缓解 exposure bias。
  • 梯度裁剪：把梯度范数限制在阈值内（常用 1.0 或 5.0），是抑制梯度爆炸的标配，对 RNN 尤其有效。
  • 截断 BPTT：把长序列切成固定长度的子段（如 64–128 步），在每段内反向传播，以控制显存并保留足够上下文。
  • 输入标准化：RNN 对尺度敏感，必须先标准化或归一化，否则训练不稳。
  • 维度约定：PyTorch 的 nn.LSTM 默认输入形状为 (seq_len, batch, features)，使用 batch_first=True 时才是 (batch, seq_len, features)，二者不能混。

本节不给出 PyTorch 训练代码：本书示例依赖只覆盖 numpy / statsmodels / scipy，Torch 需自行安装。下一节改用 numpy 实现一次 LSTM 前向，亲手算一遍门控。

08 · Python 实验：手算一次 LSTM 前向

下面用 numpy 实现一个最小的 LSTM 前向：固定随机权重，在一个短序列上逐步更新细胞状态与隐藏状态，并检查输出形状。只依赖 numpy。

import numpy as np
rng = np.random.default_rng(2301)
T, d, H = 6, 1, 4                 # 6 步、特征 1 维、隐层 4 维
X = rng.standard_normal((T, d))
sig = lambda z: 1 / (1 + np.exp(-z))
W = {k: rng.standard_normal((H, H + d)) * 0.5 for k in "fioc"}
b = {k: np.zeros(H) for k in "fioc"}
h, c = np.zeros(H), np.zeros(H)   # 初始状态清零

for t in range(T):
    z = np.concatenate([h, X[t]])
    f = sig(W["f"] @ z + b["f"])           # 遗忘门
    i = sig(W["i"] @ z + b["i"])           # 输入门
    o = sig(W["o"] @ z + b["o"])           # 输出门
    ct = np.tanh(W["c"] @ z + b["c"])      # 候选细胞状态
    c = f * c + i * ct                     # 加法式更新
    h = o * np.tanh(c)                     # 暴露到隐藏状态

print("末步 h =", np.round(h, 3))          # 具体数值取决于随机权重
assert h.shape == (H,) and X.shape == (T, d)

预期结果：循环结束后得到一个长度为 4 的隐藏状态向量，形状与 H 一致。这是对门控计算的形状/机制验证，不代表任何训练效果；真实训练还需要反向传播、优化器与上一章的时序验证。

09 · 小结

RNN 用隐藏状态携带记忆、用权重共享处理可变长序列；但沿时间连乘的梯度容易消失或爆炸。LSTM 用细胞状态与门控为梯度开出一条衰减更慢的加法通道，GRU 用两个门做到类似效果。双向结构不可用于纯预测（会用未来），Seq2Seq 与自回归生成适合多步预测但需面对误差累积。

上手 RNN/LSTM 前请先回答：序列多长、最长依赖需要记多少步？输入标准化了吗？验证是否按时间划分并留间隔？双向是否误用到了预测任务？多步预测用直接多输出还是自回归，误差累积评估了吗？
