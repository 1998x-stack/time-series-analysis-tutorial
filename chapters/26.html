CHAPTER 26 / 28 · FOUNDATION & DIFFUSION

基础模型与扩散模型

上一章的注意力机制带来了新的可能：如果先在大量序列上预训练一个通用模型，新任务只需给一段历史、不做训练就能预测呢？这一章讲清时序的 token 化、zero-shot 与微调的取舍，以及扩散模型如何给出预测分布。

机制图解 · 原生数学排版 · 可复现模拟 · 结论边界

基础模型（foundation model）的卖点不是“在某个数据集上刷分”，而是零样本迁移：把在大规模、多样化序列上训练过的通用模型直接用在没见过的序列上。扩散模型则换了一个目标——不预测单点，而是生成完整的预测分布。

本章处在课程的前沿位置，因此会更明确地区分“已发表的结果”和“仍在演进的观点”。任何具体数字都应在原始论文中核对。

01 · 为什么需要基础模型

传统流程里，每遇到一条新序列，都要重新做分解、选模型、调参、验证——短则几天，长则数周。基础模型提出另一种可能：在大规模、多来源的序列上预训练一个通用模型，面对新任务时不再训练，直接推理。

它和第 21 章的自动预测工具解决的是不同问题：Prophet、statsforecast 自定了“分解假设 + 拟合流程”，但每条序列仍要自己拟合；基础模型则把“学到的序列先验”存进了权重，推理时不再更新参数。注意后者的代价：它依赖训练分布与你的数据相似，且通常是黑箱。

02 · 时序的 Token 化

语言模型处理的是离散 token，而时间序列是连续浮点数，因此“如何把连续序列变成 token”是基础模型的第一个设计选择。主流有两种：

  • Patch embedding：把序列切成等长补丁，每个补丁经一个线性/MLP 映射成一个向量。这与上一章 PatchTST 的思路一致，保留了连续值信息。
  • 分桶量化（binning）：先对序列缩放，再把连续值落进固定数量的等宽桶，用桶号当 token。Chronos 系列把连续值按上下文窗口的平均绝对值缩放后，量化到固定数量的桶中。这样就能直接复用语言模型的架构与训练基础设施。

03 · Zero-shot 还是 Fine-tune

基础模型的实际使用只有两种模式：

  • Zero-shot：直接加载预训练权重，在你的序列上推理，不更新参数；
  • Fine-tune：从预训练权重出发，用你的领域数据做少量微调。

公开报告的大致方向是：数据模式较“通用”（清晰的趋势与季节）时，zero-shot 就能与调好的统计模型竞争；模式高度领域专有时，微调能带来提升。但具体的胜负取决于数据集、预测长度与指标，不能一概而论。稳妥做法：先跑 zero-shot 当作强基线，再用自己的时序验证决定是否值得微调。

不要跳过基线：无论基础模型多新，都应和 seasonal-naive 以及一个调好的统计模型对比，并用同一套按时间的验证（第 22 章）。否则无法区分“模型真的更强”与“评估流程出了问题”。

04 · 扩散模型：生成分布而非单点

扩散模型的思路分两步：前向过程逐步往数据里加噪声直到变成纯噪声；反向过程学习逐步去噪，从噪声恢复数据。前向过程可以解析写出：

xt=α‾tx0+1−α‾tε,ε∼N(0,I)
ᾱt 是累积的噪声保留比例，随 t 增大而趋于 0，因此 xt 逐渐变成标准正态噪声。反向过程学一个网络预测所加的噪声ε，逐步去掉它。

06 · 优势与局限

方面基础模型扩散模型
核心优势零样本迁移、跨序列复用、上手快给出完整预测分布、支持条件生成与插补
主要局限依赖训练分布、可解释性差、难审计多步去噪导致推理慢、训练成本高
数据假设需要与预训练语料相似需要足够样本估计分布
适用场景快速基线、序列量大且共性明显需要区间/情景的决策（风险、库存）
评估上的一致性：这两类模型仍需用第 22 章的时序交叉验证、与 seasonal-naive 基线对比，并报告多个预测区间的校准情况。新方法不自动等于更好，尤其在可解释性与推理成本上会引入新的约束。

07 · Python 实验：分桶 token 化与前向加噪

下面用 numpy 实现一个简化的分桶 token 化（按上下文缩放后分桶），并用前向公式验证“加噪到末期近似标准正态”。只依赖 numpy。

import numpy as np
rng = np.random.default_rng(2601)

# 1) 简化的分桶 token 化：按上下文平均绝对值缩放，再落入等宽桶
def tokenize(x, n_bins=8, clip=3.0):
    v = x / (np.abs(x).mean() + 1e-8)
    v = np.clip(v, -clip, clip)
    idx = np.floor((v + clip) / (2 * clip) * n_bins).astype(int)
    return np.clip(idx, 0, n_bins - 1)

x = np.array([2.0, 5.0, 1.0, 8.0, 3.0])
print("token:", tokenize(x))              # → [4 5 4 6 5]

# 2) 前向加噪：末期 x_t 的方差趋近 1（与 x0 尺度无关）
T = 500; beta = np.linspace(1e-4, 0.02, T)
abar = np.cumprod(1 - beta)
x0 = rng.standard_normal(5000) * 2.0
for t in (0, 250, 499):
    xt = np.sqrt(abar[t]) * x0 + np.sqrt(1 - abar[t]) * rng.standard_normal(5000)
    print(f"t={t:3d}  方差={xt.var():.3f}  信号系数={np.sqrt(abar[t]):.3f}")
assert np.sqrt(abar[-1]) < 0.1          # 末期信号几乎被噪声淹没

预期结果：序列被映射成桶号（如 [4 5 4 6 5]）；随 t 增大，加噪后方差逐渐趋近 1（约为 3.89 → 1.75 → 1.00），信号系数趋于 0。这是对 token 化与前向过程语义的数值验证，不代表任何生成或预测效果。

08 · 小结

基础模型把“预训练 + 零样本迁移”的思路带进时序，关键是 token 化（patch 或分桶）；扩散模型则把目标从点预测换成分布生成，擅长概率预测与插补。它们都有明确的代价：前者依赖训练分布且难解释，后者推理需多步去噪。

引入这些新方法前请先回答：它和 seasonal-naive/统计模型在同一时序验证下的结果如何？预测区间是否校准？推理成本能否满足上线要求？当预测失误时，你能解释原因吗？
