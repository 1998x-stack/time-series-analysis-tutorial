CHAPTER 19 / 28 · FEATURE ENGINEERING

时序特征工程

把一条有序序列安全地变成监督学习的“表格”，是树模型与神经网络能用上时间信息的前提。这一章讲清滞后、滚动、日历与傅里叶特征，以及最危险的敌人——数据泄露。

机制图解 · 原生数学排版 · 可复现模拟 · 泄露诊断

前 18 章我们走完了经典时间序列的核心：AR、MA、ARMA、ARIMA、季节结构、波动率、VAR、协整与状态空间。它们都以“序列自身的动态”为建模对象。从这一章开始，主战场转向机器学习：树模型、梯度提升、神经网络都属于“给定特征 → 预测目标”的通用框架，本身并不知道时间是先后有序的。

因此，把时间结构编码成特征就成了成败关键。做对了，模型能利用历史；做错了，模型会偷偷看到未来，得到漂亮却无意义的分数。这一章的目标不是罗列技巧，而是让你对“信息集边界”保持敏感。

01 · 从序列到监督学习表格

普通监督学习假设样本独立同分布，可以随机打乱、随意划分。时间序列恰好相反：相邻观测高度相关，顺序本身携带信息。桥接两者的标准做法是滑窗变换——用过去一段窗口构造特征，去预测某个未来时刻的目标。

引入两个关键设计量：窗口长度 L（回看多少期）与预测步长 h（往前预测多远）。样本 t 的特征只允许来自 yt, yt−1, …, yt−L+1，目标是 yt+h。当 h ≥ 1 时，特征与目标天然错开至少一步，这与“用 yt 预测 yt”是两回事。

滑窗生成的监督学习表格（L=2，h=1）
样本特征 lag_2特征 lag_1目标 y(t)
t=3y₁y₂y₃
t=4y₂y₃y₄
t=5y₃y₄y₅

注意表格里的“行”其实是同一段历史的不同切面：第 3 行与第 4 行共享 y₂、y₃。这种重叠意味着样本量被高估，也意味着不能把随机打乱当作增强。

02 · 滞后特征

最基础的特征是滞后值 lag_1, lag_2, …, lag_k。选多少阶滞后有两个来源：统计线索与领域知识。

统计上，第 4 章的偏自相关函数（PACF）给出候选：显著超出置信带的滞后阶数值得纳入。但要记住 第 4 章强调过的边界——有限样本的 PACF 与总体截断点并不完全一致，它只是线索而非判决。领域知识同样重要：预测日度零售销量时，过去 7 天的滞后通常比第 6 天更有用，因为存在周周期。

实践中可以先用一个较大的滞后集合（例如过去 30 期），再让树模型的特征重要性或 Lasso 做筛选。模型对冗余特征通常有一定容忍度，但滞后阶数过大也会引入噪声、增加过拟合风险，仍需交叉验证确认。

一个容易被忽略的约束：特征必须在预测时刻真实可得。如果某变量的发布有滞后（如月度 GDP 要到季末才公布），把它当作当期特征就是在用当时拿不到的信息。这一条约束比任何算法选择都更根本。

03 · 滚动窗口统计量

仅用原始滞后值不够。局部趋势与波动水平往往比精确的过去值更有信息量，而滚动统计量正好把它们提炼出来。常见的滚动特征包括：

  • 滚动均值：过去 L 期平均，反映局部水平；
  • 滚动标准差：过去 L 期波动，反映局部不确定性；
  • 滚动最小/最大值与极差：过去 L 期的区间边界；
  • 滚动分位数（中位数、25%/75%）：对异常值更稳健；
  • 滚动斜率：对窗口做线性回归得到的斜率，反映局部变化速度。

以滚动均值为例，窗口长度为 L 时，时刻 t 的特征是：

y‾t(L)=1L∑i=t−L+1tyi
这个定义本身是“截至 t 的历史汇总”，并不含未来。泄露风险不来自公式，而来自与目标的对齐：如果目标是 yt，那么用含 yt 的滚动均值去预测它，就已经越界。

同理，滚动 z 分数 (y_t − 滚动均值) / 滚动标准差 依赖同期 yt，它适合做异常检测（事后标记），却不适合作为预测同期的特征。

可以形成一条稳定规则：先把所有特征算出来，再统一向后平移 h 步去对齐目标。这比在每个函数里手动防错更可靠。

04 · 数据泄露的几种形态

数据泄露是时序机器学习中最隐蔽、代价最高的错误。它不一定报错，却会让离线分数虚高、上线后崩溃。常见形态至少有四类：

泄露形态表现修正
目标泄露特征含目标同期或未来信息（如忘了 shift）特征统一向后平移 h 步对齐目标
预处理的泄露在全量数据上拟合 scaler / 插补器 / 异常阈值只用训练段拟合，再 transform 验证段
不可得特征使用了当时尚未发布的变量或后验汇总按发布延迟对齐特征时间戳
划分的泄露随机切分、重叠窗口跨界按时间切分并加间隔（purge/embargo）

其中“预处理的泄露”最容易被忽视：均值和标准差本身就是从数据估出来的参数，用全量数据估计就等于让训练段“了解”了验证段的分布。正确的流程是只在训练段 fit，再 transform 验证段，验证段的新数据一律不参与统计。

可执行的判据：对任意样本，若把目标 yt+h 随机重排而特征不变，模型的离线分数应明显下降。如果重排后分数几乎不动，几乎可以断定特征里混入了目标信息。

05 · 日历与傅里叶项

时间坐标本身携带大量信息：小时、星期几、月份、是否节假日、月中/月末等，都能帮助模型捕捉人类社会的周期性行为。对于固定周期的季节波动，更好用的编码是傅里叶项：用若干对正弦、余弦函数逼近任意周期形状。

周期长度为 P、阶数为 k 的一对傅里叶项定义为：

sk(t)=sin(2πktP),ck(t)=cos(2πktP)
t 是单调递增的时间索引（不要每年清零），P 是周期长度（周周期 7，年周期 365.25）。k 越大频率越高，能拟合的周期形状越尖锐，但同样增加过拟合风险。

阶数 k 不应无界增大。离散采样的一个基本限制是：一个周期内最多分辨 P/2 个独立频率成分（即 k ≤ P/2），超过它只能拟合噪声。可以同时为多个周期叠加傅里叶项，例如日度数据用 P=7 取 2–3 对捕捉周内形状，再用 P=365.25 取若干对捕捉年内季节。

循环编码 vs 数值编码：月份、星期几这类循环变量若只用数值 1–12 表示，树模型会默认 12 与 1 相距很远，而它们其实是相邻的。同时保留数值编码与 sin/cos 编码，让模型自行选择更合适的切分方式。

06 · 缺失值处理

时序缺失比普通表格更棘手：不能随意删行，否则打乱时间间隔。处理前先弄清缺失机制——是完全随机、与取值相关，还是与时间相关（如设备夜间停机）。不同机制下合适的方法不同。

方法适用场景风险
前向填充 ffill短缺口、取值变化缓慢引入阶梯滞后
线性 / 样条插值趋势平滑且缺口不长在拐点处失真；插值会用到后向信息
季节插值有强周期需先对齐周期相位
模型预测填充长缺口成本高，会把模型偏差带入特征
直接删除缺失极少且非连续改变采样节奏

有一个简单而稳健的基线：前向填充，并加一个“是否被填充”的指示列。标记列告诉模型“这个值是真实观测还是填充的”，让它自行决定是否信任。

实时与回测的差异：线性插值、用后向值回填都使用了未来信息。若模型要在线运行或做回测，必须改用仅依赖过去的填充（如 ffill），否则同样是泄露。这是“方式本身没错，场景用错”的典型。

07 · 异常检测

时序异常可能是传感器故障、录入错误，也可能是真实事件信号（促销、突发需求）。在特征工程阶段，至少要能识别它们，而不是盲目删除或截断。

最常用的两种全局判据：Z-score（距均值多少个标准差，通常 |z|>3 视为异常）与IQR（超出 Q1−1.5·IQR 与 Q3+1.5·IQR 之外）。两者都有局限：Z-score 假设近似正态且均值和标准差本身会被极值污染；IQR 不感知时序局部性，序列整体的正常值在局部可能看似异常。

更贴合时序的做法是滚动窗口版本：用过去 L 期的均值与标准差计算局部 z 分数，从而感知局部波动水平。这与前面的滚动统计量是同一套工具。

import numpy as np

def rolling_zscore(y, window=30):
    """滚动局部 z 分数：第 t 期的均值/标准差只用 y[t-window+1..t]。"""
    y = np.asarray(y, dtype=float)
    z = np.full(y.shape, np.nan)
    for t in range(window, len(y)):
        seg = y[t - window:t]          # 不含 y[t]，避免用自己的值判断自己
        sd = seg.std(ddof=1)
        if sd > 0:
            z[t] = (y[t] - seg.mean()) / sd
    return z

flag = np.abs(rolling_zscore(y, 30)) > 3.0

注意这里把窗口写成 y[t-window:t]（不含 y[t]）：用同期值判断它自己是否为异常，会把异常拉进均值里、稀释信号。若分布明显受极值污染，把均值/标准差换成中位数/MAD 会更稳健。此外，异常不必等于删除：如果异常是真实事件，保留它并加上“异常标记”列，往往比直接剔除更有价值。

08 · Python 实验：“含当前值的滚动均值”到底泄露了什么

下面用一个确定随机种子的合成序列（趋势 + 周周期 + 噪声）对比两种滚动均值：泄露版含当期 yt，诚实版不含。目标是用它们预测当期 yt（即开现在值，在真实系统里当期值尚不可得）。只依赖 numpy。

import numpy as np
rng = np.random.default_rng(1900)
n = 300
eps = rng.standard_normal(n)
y = np.empty(n); y[0] = 0.0
for i in range(1, n):
    y[i] = 0.9 * y[i-1] + eps[i]        # 持续性强的时间序列

L = 2
leaky = np.array([y[max(0, i-L+1):i+1].mean() for i in range(n)])  # 含 y_t
truth = np.concatenate([[np.nan], leaky[:-1]])                    # 不含 y_t

cc = lambda a, b: float(np.corrcoef(a, b)[0, 1])
print("corr(leaky, y) =", round(cc(leaky, y), 4))          # ≈ 0.9755
print("corr(truth, y) =", round(cc(truth[1:], y[1:]), 4))  # ≈ 0.8881
assert cc(leaky, y) - cc(truth[1:], y[1:]) > 0.05         # 泄露让特征“更像”目标

预期结果：含当期值的特征与目标相关系数约为 0.9755，不含当期值的约为 0.8881，差约 0.09——这一截差异就是 yt 直接漏进来的部分。这是合成数据上的机制验证，不代表任何真实数据集的预测水平；真实项目里可用同样的“相关系数异常地高”体检来排查泄露。

09 · 检查清单

每次做时序机器学习项目，可以逐项核对：

  • 特征与目标的时间对齐步长 h 在所有分支上一致吗？滚动特征是否统一平移了 h 步？
  • scaler、插补器、异常阈值只在训练段拟合了吗？
  • 所有特征在预测时刻都真可得吗（无发布延迟、无后验汇总）？
  • 训练/验证是按时间切分并留了间隔吗（参见第 22 章）？
  • 缺失值的填充方式在线与回测时是否一致？
  • 异常是被保留并标记，还是被默默删除了？
一句话原则：任何一行样本，其特征只能来自该行目标时刻之前的信息。把所有特征画出时间轴、标出每个特征的“信息截止时刻”，是发现泄露最快的办法。下一章我们把这套特征工程用于树模型，并讨论它为何在表格类时序任务中常胜过单一 ARIMA。
