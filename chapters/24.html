CHAPTER 24 / 28 · CONVOLUTIONS

卷积与时序

RNN 必须串行计算，难以充分并行。一维卷积沿时间滑动做模式匹配，膨胀与因果设计让它既能看得很远、又不会偷看未来。这一章讲清卷积如何用在序列上，以及 RNN 与 CNN 的取舍。

机制图解 · 原生数学排版 · 可复现模拟 · 因果性检查

卷积在图像上匹配空间模式（边缘、纹理），在时间序列上匹配时间模式（上升段、尖峰、周期形状）。它不依赖循环，所有时间步可以并行计算，因此在同样硬件上通常比 RNN 训练得快。

但要把它用在预测上，有两个前提必须满足：能覆盖足够长的历史（感受野），以及绝不看到未来（因果性）。这一章正是围绕这两点展开。

01 · 一维卷积：局部模式匹配器

一维卷积用一个长度为 K 的卷积核在序列上滑动，每个位置计算窗口内数值与核权重的点积。写成公式，膨胀率为 d 时，时刻 t 的输出是：

yt=∑k=0K−1wkxt−dk+b
K 是核长（一次看到多少个时间步），d 是膨胀率，wk 是在所有位置共享的权重。因为权重共享，参数量与序列长度无关。

02 · 膨胀卷积与感受野

普通卷积的“视野”（感受野）很小：核长 K 的一层只能看到 K 步。膨胀卷积在核元素之间插入 d−1 个间隔，使一层覆盖 (K−1)·d + 1 步而不增加参数。多层堆叠时，感受野会随层数近似线性增长：

R单层=1+(K−1)d
当膨胀率按 1, 2, 4, 8, … 指数增长时，层数很少就能把感受野推到很远（指数量级），这是 TCN 高效的关键。
d=2，k=3：4 层后感受野约 31 期；d=1 时仅 9 期。

教学示意：4 层、卷积核 k=3 的膨胀因果卷积，第 l 层膨胀率为 d 的 l−1 次幂；柱高为每层累积感受野（已按最大值归一），横轴为第 1 到 4 层。

03 · 因果卷积与 WaveNet

预测必须遵守时间顺序：时刻 t 的输出只能依赖 t 及之前的数据。普通卷积在 padding 时很容易把未来值卷进来，因果卷积（causal convolution）通过只在左侧填充、不读右侧，严格保证“不看未来”。膨胀因果卷积则是把膨率与因果性结合。

WaveNet（van den Oord 等，DeepMind，2016）最初为原始音频生成设计，用的是堆叠的膨胀因果卷积，生成的人声质量在当时达到领先水平。因为它的结构本质上适用于任何序列，随后被广泛迁移到语音识别、音乐生成与时间序列预测。这是一个很具体的例子：为一个领域设计的架构，因为抽象层次足够高，会在另一个领域同样有效。

用因果性检查代替假设：不要“相信”代码是因果的——写一个小测试：把序列未来部分改动，看过去的输出是否变化。不变才算因果（下一节实验就做这件事）。

04 · TCN 与残差连接

时序卷积网络（TCN）的论文（Bai、Kolter、Koltun，2018）把两个设计组合起来：膨胀因果卷积提供大感受野，残差连接提供稳定的梯度通路。原始论文在多个序列建模基准上报告 TCN 超过同规模的 LSTM，但这依赖具体任务与调参，不能当作普遍结论。

残差连接的关键是：每个卷积块的输出与该块的输入相加（必要时用 1×1 卷积对齐通道）。这样梯度可以直接跳过卷积层反向传播，缓解深层网络的退化。

05 · CNN-LSTM 混合架构

CNN 擅长抽局部形状，LSTM 擅长长程依赖，于是可以把两者串起来：先由 1D 卷积（或 TCN）把序列变成一组局部特征序列，再交给 LSTM 建模长期关系。这种“先局部后全局”的设计在不少任务上比单一结构好。

  • 并行式 CNN-LSTM：两条分支分别处理输入，再融合输出；适合同时需要局部与全局的任务。
  • ConvLSTM：把 LSTM 内部的矩阵乘换成卷积，适合具有空间结构的序列（如雷达回波外推）。

需要警惕：混合结构层数更多、更易过拟合，而且仍然是串行的（LSTM 部分），并行优势被削弱。

06 · RNN 还是 CNN？

维度RNN / LSTMCNN / TCN
并行计算串行，步与步之间有依赖沿时间可并行
感受野理论上无界，但实际受梯度限制由层数与膨率显式控制
梯度稳定性需门控与裁剪残差连接缓解
参数量较大（LSTM 有四个门）较小（权重共享、无循环）
变长序列天然支持、可重置状态需固定窗口或处理长度变化

没有普遍更好的结构。定长窗口、大数据、追求速度时优先试 CNN/TCN；变长序列或需要状态重置时优先试 RNN。最终仍应用第 22 章的时序验证来选。

07 · Python 实验：因果卷积与感受野

下面用 numpy 手写一个因果膨胀卷积，并用“改动未来值”的方式检验因果性，同时验证感受野公式。只依赖 numpy。

import numpy as np

def causal_conv1d(x, w, d):
    """因果膨胀卷积：时刻 t 只用到 x[t-dk]（k=0..K-1，索引 >=0）。"""
    K, T, y = len(w), len(x), np.zeros(len(x))
    for t in range(T):
        for k in range(K):
            i = t - d * k
            if i >= 0:
                y[t] += w[k] * x[i]
    return y

x = np.arange(1, 11, dtype=float)
w = np.array([0.5, 0.3, 0.2])
y = causal_conv1d(x, w, d=1)

x2 = x.copy(); x2[-1] += 100          # 只改动最后一个（未来）值
y2 = causal_conv1d(x2, w, d=1)
print("前 9 步是否不变:", np.allclose(y[:-1], y2[:-1]))   # True
assert np.allclose(y[:-1], y2[:-1])

K, ds = 3, [1, 2, 4]                  # 3 层，膨率指数增长
print("感受野:", 1 + sum((K - 1) * d for d in ds))        # 15

预期结果：改动最后一个值后，前 9 步输出完全不变，证明因果性；三层（K=3，膨率 1、2、4）的感受野为 15 步。这是对卷积语义与因果性的形状验证，不代表任何训练效果。

08 · 小结

一维卷积把时间模式当作可匹配的局部形状，可沿时间并行；膨胀卷积用指数增长的间隔扩大感受野；因果卷积保证不看未来。TCN 把这三者与残差连接组合，在多项序列任务上与 RNN 竞争。它也有代价：定长窗口、对超长依赖仍需足够层数。

用卷积做预测前请先回答：卷积是否因果（用改动未来的测试验证过）？感受野能否覆盖业务关心的最大滞后？膨率组合是否在验证集上确认？序列尺度是否标准化？最后的评估是否用了按时间的验证？
